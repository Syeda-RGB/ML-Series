
# Unsupervised Learning Practice

This folder contains my hands-on practice of important Unsupervised Learning concepts.

## Topics Covered

- K-Means Clustering
- Elbow Method
- DBSCAN Clustering
- PCA (Principal Component Analysis)
- Curse of Dimensionality

## Practical Work

In this notebook, I practiced:

- Creating synthetic datasets using `make_blobs`
- Applying K-Means clustering
- Using the Elbow Method to choose a suitable number of clusters
- Applying DBSCAN on irregularly shaped data
- Understanding how DBSCAN detects noise and outliers
- Reducing high-dimensional data using PCA
- Visualizing clustering results

## Key Learnings

- K-Means works well when clusters are clearly separated and roughly spherical.
- The Elbow Method helps estimate a suitable value of `K`.
- DBSCAN can detect clusters of different shapes and can identify noise points.
- PCA helps reduce the number of dimensions while preserving important information.
- High-dimensional data can make distance-based algorithms less effective due to the curse of dimensionality.
